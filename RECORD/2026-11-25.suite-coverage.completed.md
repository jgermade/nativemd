# Suite coverage (`--coverage`)

## 2026-11-25

- `nmd_suite_main` gained `--coverage FILE`: the oracle's executed instruction addresses,
  accumulated over all the states of a suite (the routine and everything it calls), in the
  format of `nmd-oracle --coverage`. Coverage now survives the per-state machine resets
  (it is enabled once, after the throwaway init).
- Motivation (Sonic 1 client): mutation checks only find holes for the mutations someone
  thinks of; the client now reports, per routine, the reachable instructions no state
  executes. Its first run found a real hole (Newtron's landing after the drop, never
  executed by any state) and three instructions that no game state can reach.
- docs/harness.md and harness/suite.h document the option.
