# Suites of interrupt handlers: registers around the C

## 2026-11-26

- Found while giving C to Sonic 1's VBlank handler (nativemd-internal,
  `RECORD/2026-11-27.level-loop.WIP.md` there). `nmd-suite --irq` ran the oracle side
  through an exception frame and `RTE` (registers and SR restored by the handler's own
  `movem` and the `RTE`), but called the C directly: a handler that uses registers left them
  changed, while the engine itself saves and restores `M68K` around every handler
  (machine.c `take_interrupt`). So the two sides were not compared on the same terms.
- Fix: with `--irq`, `harness/suite.c` saves `M68K` before calling the C and restores it
  after, exactly as `take_interrupt`. docs/harness.md updated. The hello VInt / HInt
  suites still pass (22/22 tests).
