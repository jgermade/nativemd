# VDP renderer (milestone 4)

Asked by the user to see the Sonic 1 client's progress as pictures (no third-party
emulator screenshots: our engine, our C). Branch `ccr-c03681be-48dioy`.

## 2026-11-28 — first version

- `src/render.c`: one active line at a time, called by `vdp_line` before the HINT check,
  so the engine (`vdp_frame`) and the oracle (its own line loop) both draw, and HINT
  handlers' changes (LZ's water palette) show from the next line. Mode 5: planes, window,
  sprites with their limits and X = 0 masking, priorities, backdrop, left column blank,
  display off; colours 3 bits per channel scaled to 0-255. Not yet: shadow / highlight,
  interlace, mode 4, the partial first column of two-cell vertical scroll.
- `nmd_framebuffer(&w, &h)` (public); `machine.c` presents it to the host.
- Cost: drawing every line made a 9000-frame hybrid run 8x slower (3.5 s -> 27 s), which
  would have slowed every check. `nmd_config.no_render` skips drawing; the suites and
  nmd-oracle always set it, the hybrid runners unless `--screenshot` is given. Plane
  drawing then fetched per cell instead of per pixel: 16 s with drawing, 3.2 s without.
- `harness/png.c`: PNG without zlib (stored deflate blocks). `--screenshot N:FILE.png`.
- `tests/test_render.c`: backdrop, tile pixel, H / V flip, palettes, plane / sprite
  priorities, the 21st sprite on a line, line scroll, the window, display off. 23/23.
- Sonic 1 client runs: Sega / title fade, GHZ with its title card, LZ above and below the
  water line, SBZ 1 / 2: as expected; the hybrid run with C and without C give
  byte-identical PNGs.

## 2026-11-28 — desktop host

- `host/sdl/sdl_host.c` (optional library `nmd_sdl`, built when CMake finds SDL2): window
  (scaled, resizable, F11 fullscreen), keyboard and the first game controller as pad 1,
  frame pacing at the video rate (performance counter, resynchronised when late), pause,
  fast forward. The engine stays platform-free: the host is only a `nmd_host` table.
- `harness/play.c`: `nmd_play_main()`, the hybrid runner with that host; `nmd-play` (no C).
- Checked here without a display (`SDL_VIDEODRIVER=dummy`): the Sonic 1 client's `s1-play`
  runs 600 frames in 10 s (60 Hz), quits cleanly. Keyboard / controller input could not be
  exercised in the container (no display, no input devices).
